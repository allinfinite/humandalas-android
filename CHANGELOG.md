# Changelog

## 2.0.0 — 2026-09-21

- Rebuilt Humandalas as a modern native Android app targeting API 36.
- Added an offline 46-card library with stage filtering and card details.
- Added a complete randomized five-stage guided Humandala.
- Added system text sharing for individual cards.
- Removed analytics, ads, push, billing, cloud credentials, remote downloads, and proprietary runtime dependencies.
- Replaced provenance-unclear media with runtime-drawn geometric artwork.
- Released the complete rebuild under GPL-3.0-or-later.
